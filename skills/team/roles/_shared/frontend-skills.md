## Frontend skills

When these skills are available (the `frontend` add-ons: `tw.py addons add frontend`), use the
ones your work needs and say which you used; when one is missing, work without it and say so:

- `impeccable`: design, critique, audit, polish, harden or animate an interface; its
  `audit` and `critique` commands for reviews, `polish` before a release.
- `design-taste-frontend` (taste): art direction for public pages (landing, marketing,
  portfolio, product pages) and app screens; no templated, "AI-made" look.
- `frontend-design`: a distinctive visual direction (type, color, composition) for new UI.
- `solar-icons`: the Solar icon set; take exact icon names and the framework's import from it,
  never invent an icon name.
- Cloudflare: `turnstile-spin` for bot checks in forms, `web-perf` for Core Web Vitals.

The project's own design system and conventions come first: a skill's taste never overrides
what the repository already decided.
