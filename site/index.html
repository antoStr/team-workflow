The problem and the fix

A single AI assistant works alone. It writes the code, approves its own code, says "Fixed!" without starting the app, and forgets your project the next day. team-workflow gives the assistant a team and a set of rules it cannot talk its way around.

Install in 30 seconds

You need: git, Python 3 and one of the supported apps.

Claude Code

claude plugin marketplace add antoStr/team-workflow
claude plugin install team@team

Restart Claude Code, then type /team <what you want>. That is all.

agy (Antigravity)

agy plugin install https://github.com/antoStr/team-workflow
python ~/.gemini/config/plugins/team-workflow/skills/team/scripts/tw.py install-cli

Restart agy.

OpenCode (CLI or desktop app)

git clone https://github.com/antoStr/team-workflow
python team-workflow/skills/team/scripts/install_opencode.py

Restart OpenCode. Commands: /team or /team-workflow/<name>.

Codex / opencodex

git clone https://github.com/antoStr/team-workflow
python team-workflow/skills/team/scripts/tw.py install-codex

Restart Codex. Commands: $team or $team-workflow-<name>.

See it work

An example session (shortened):

you    /team the game crashes on the stage 3 boss

team   setup    a few quick questions: scope, which specialists, which models
       plan     backend-dev fixes, tester verifies, code-reviewer reviews
       talk     #1 backend-dev → tester   [fix]       null boss sprite after reload
                #2 tester → backend-dev   [challenge] still crashes on a second retry
                #3 backend-dev → tester   [fix]       sprite reloaded on every retry
                #4 tester                 [verdict]   12 tests pass, game boots and runs stage 3
       smoke    tw.py smoke "npm run start" → process alive after 10 s, no errors
       learn    "reload assets on retry" saved as a check for the next time
       report   what changed, the proof, and anything that still needs your OK

Why it does not fake it

Most AI tools rely on instructions the model can skip. team-workflow puts the important rules in code that runs on its own:

  1. Zero Fake-Solved. A bug is not fixed until tw.py smoke "<launch command>" starts the real app and it stays up (exit code, stderr, a few seconds of runtime). On Windows, --wsl runs it in Linux.
  2. No self-approval. Agents work on a shared channel (tw.py talk). Under the adversarial gate (tw.py gate) the author cannot approve its own work: a verifier has to.
  3. Mistakes become checks. A lesson is saved with tw.py learn record. If a regex can find the mistake, add --check-pattern. From then on a hook blocks the mistake on every edit, at the end of the session and in CI (tw.py learn check). Lessons without a check are passed to the agents as reminders.
  4. The setup cannot be skipped by accident. In Claude Code a hook holds the team agents until the setup questions are answered (or you say "skip setup").
  5. It asks before anything irreversible. Changes outside the task are listed in the final report and wait for your consent.

Documentation is checked too: tw.py verify-docs is part of the closing steps, and the final report includes its result next to the smoke-test output.

Rule 3 follows the lesson of "All Code Is Slop (Except Mine)" (Lauren Tan, AI Engineer 2026): every correction should become a deterministic check, not one more line of instructions.

FAQ

Is it alpha?

The alpha testing guide (ALPHA_TESTING.md) covers v2.0.0-alpha.1: the Brain engine, the Dual Loader, the Rolling Digest in talk channels and Windows portability. The current release is v2.5.4. To report an anomaly, open an issue or share the output of tw.py doctor.

Does it work on Windows?

Windows is handled in the code: tw.py smoke --wsl runs the launch command in Linux, and python_executable() skips the 0-byte Microsoft Store Python placeholders. The CI workflow runs on ubuntu-latest (Python 3.10 and 3.15), so there is no Windows CI run.

Is it free?

Yes. It is under the MIT License, which grants permission "free of charge" to use the software. Imported third-party resources keep their own licenses (NOTICE). /team upgrade updates the plugin with a local script, so it uses no tokens.

Do I have to use all 137 agents?

No. The lead agent picks only the specialists the task needs, and works alone on small tasks.

How does it stop the agents from claiming a fix that does not work?

The fix is accepted only after tw.py smoke starts the real command and the process stays healthy, and after an independent verifier signs off.

Can I skip the session setup?

Yes. Write "skip setup" in the request, or answer just "defaults", to start with your current settings. TEAM_WORKFLOW_SETUP_GATE=0 or session_wizard=false turns the setup gate off.

Can it change files without asking?

No. It only touches files that belong to your task. Anything else is proposed in the final report and waits for your OK.

Does it work on long projects?

Yes. The memory and the brain graph keep the project's state across sessions, and tw.py brain rollover archives old history into weekly journals.
